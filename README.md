# Museum Tycoon: Lost Treasures

A multiplayer Roblox museum tycoon: build your museum, explore the Forgotten Ruins, discover artefacts, display them, earn from visitors, and grow your prestige.

This project is written for **VS Code + Rojo**. All code lives in `src/`. The whole map (plots, museums, the ruins zone, portals) is **generated by code when the server starts**, so you don't have to build anything by hand in Studio.

> Honest note: this code was type-checked with the Luau language server (Roblox API definitions) and has zero errors, but it has **not** been run inside Roblox Studio yet — I can't run Studio from here. Follow the test checklist in Part 4. If anything errors, copy the red text from the Output window and send it to me together with the script name.

## Part 1 — One-time setup

### 1.1 Install the programs
1. **Roblox Studio** — https://create.roblox.com → "Start Creating".
2. **Visual Studio Code** — https://code.visualstudio.com.

### 1.2 Install the VS Code extensions
1. Open VS Code.
2. Click the **Extensions** icon on the left bar (four squares) or press `Ctrl+Shift+X`.
3. Search **Rojo** → install **"Rojo – Roblox Studio Sync"** by *evaera*.
4. Search **Luau Language Server** → install the one by *JohnnyMorganz*.

### 1.3 Open the project
1. Unzip `MuseumTycoon.zip` somewhere easy, e.g. `Documents\RobloxProjects\MuseumTycoon`.
2. In VS Code: **File → Open Folder…** → choose the `MuseumTycoon` folder (the one containing `default.project.json`).
3. If VS Code asks "Do you trust the authors?", click **Yes**.
4. If it suggests the recommended extensions, click **Install**.

### 1.4 Install Rojo itself and the Studio plugin
1. In VS Code press `Ctrl+Shift+P`, type **Rojo: Open Menu**, press Enter.
2. If the menu says Rojo isn't installed, click **Install Rojo** (it installs the right version for you).
   *Alternative:* if you use Rokit, open a terminal in the folder and run `rokit install` (the `rokit.toml` pins Rojo 7.7.1).
3. In the same Rojo menu, click **Install Roblox Studio plugin**. Restart Studio if it was open.
   *Alternative:* in Studio, **Toolbox → Plugins** tab (or the Creator Store), search "Rojo", install the plugin by *Rojo*.

## Part 2 — Connect VS Code to Studio

1. Open **Roblox Studio** → **New** → **Baseplate**. (The game deletes the default Baseplate and SpawnLocation automatically when it runs.)
2. **Save it first:** File → **Publish to Roblox As…** → *New game* → name it "Museum Tycoon" → Create. Publishing is required for saving player data (step 3.1).
3. In **VS Code**: `Ctrl+Shift+P` → **Rojo: Open Menu** → click **default.project.json** to start the server. You'll see "Serving on port 34872".
4. In **Studio**: **Plugins** tab → **Rojo** → click **Connect**. (Address `localhost`, port `34872`.)
5. Studio may ask to allow the plugin to change the place — click **Accept/Allow**.
6. Check the **Explorer** window (View → Explorer). You should now see:

```
ReplicatedStorage
  └─ Shared            (Folder)  ← src/shared   — ModuleScripts used by both sides
ServerScriptService
  └─ Server            (Folder)  ← src/server
       ├─ Main         (Script)
       ├─ Services     (Folder of ModuleScripts)
       ├─ Util         (Folder of ModuleScripts)
       └─ World        (Folder of ModuleScripts)
StarterPlayer
  └─ StarterPlayerScripts
       └─ Client       (Folder)  ← src/client
            ├─ Main    (LocalScript)
            ├─ ClientState, ClientNet (ModuleScripts)
            ├─ UI          (Folder of ModuleScripts)
            └─ Controllers (Folder of ModuleScripts)
```

From now on, **every time you save a file in VS Code it instantly updates in Studio.** Edit code only in VS Code — changes made to these scripts inside Studio are overwritten by Rojo.

> Rojo does *not* save your place. Press **Ctrl+S** in Studio (or File → Publish) to save the place file itself.

## Part 3 — Studio settings (do these once)

### 3.1 Turn on saving (DataStores) in Studio
1. **Home** tab → **Game Settings** → **Security**.
2. Turn ON **Enable Studio Access to API Services** → **Save**.

Without this the game still runs, but a red banner says "Progress is NOT being saved" and nothing persists.

### 3.2 Set max players to 8
**Game Settings → Places** (or **Avatar/Basic Info** depending on your Studio version) → the place's **Max Players** = **8**. There are 8 plots; a 9th player would be told the server is full.

### 3.3 Streaming
The project sets `Workspace.StreamingEnabled = false` automatically. If the Output window warns Rojo couldn't set it, select **Workspace** in the Explorer and untick **StreamingEnabled** in Properties.

| 7 | Step on the green **Grand Entrance** pad (front yard, left) | Columns, lamps and a sign rise from the ground. $150 spent. |
| 8 | Click **Travel** → Forgotten Ruins → **Travel** (or walk through the blue portal in the plaza) | You arrive in the sandy ruins; the lighting turns golden. |
| 9 | Walk to a dirt mound and press **E** | A progress bar fills (≈5 s), then a discovery card with a spinning model. |
| 10 | Search the same mound again | "You've already searched here. Come back in 59s." |
| 11 | Walk away during a search | "You moved too far away." — nothing is awarded. |
| 12 | Read the stone tablet in front of the temple, then step on plates **SUN → MOON → STAR** | "A secret door has opened!" The temple's back door turns see-through for 25 s; the hidden chamber has two glowing alcoves. |
| 13 | Click **Home** | You're back at your museum. |
| 14 | Open **Items**, select a non-displayed item → **Sell** | Cash increases by 60% of its value; the item disappears. |

| `src/shared/CollectionSets.luau` | ModuleScript | …Shared.CollectionSets | Collection sets and rewards |
| `src/shared/Upgrades.luau` | ModuleScript | …Shared.Upgrades | Upgrade costs, prerequisites, display slots, visitor routes |

| `src/server/Services/EquipmentService.luau` | ModuleScript | …Server.Services | Tool shop |

**Naming rule Rojo uses:** `Name.server.luau` → Script, `Name.client.luau` → LocalScript, `Name.luau` → ModuleScript, folder → Folder.

### Common edits
- **Rebalance prices/timers:** `src/shared/Config.luau`, costs in `Upgrades.luau`, values in `ItemCatalog.luau`.
- **Add an artefact:** add one `I(...)` line in `ItemCatalog.luau`. It automatically appears in loot, the journal and the inventory.
- **Use a real 3D model:** in Studio create a Folder `ItemModels` in ReplicatedStorage (Rojo leaves it alone), drop a Model named exactly like the item id (e.g. `coin_gold_sun`). Its pivot should be at the bottom-centre, front facing −Z.
- **Change sounds:** `Config.Sounds` — paste `rbxassetid://` IDs from the Creator Store.

## Part 7 — Update 2: Expeditions, Heists & the Collectors' Market

Existing saves are kept: the data version goes 1 → 2 automatically (every old item becomes **Clean** condition; new fields get defaults).

### What's new
| Feature | How to play it |
|---|---|
| **Improved Forgotten Ruins** | Terrain dunes, cobbled avenue, Obelisk crossroads, fallen Colossus (hidden alcove under the leaning slab), canyon with a climbable ledge, buried arches, three **Watcher statues** whose inscriptions give the glyph order. |
| **Jungle Temple Ruins** (Level 3) | Green portal in the plaza. Gate → winding path → courtyard with 4 **Guardian Pillars** and a waterfall (grotto behind it) → collapsed ruins → hidden **Root Chamber** → pyramid with an underground **sanctum**. |
| **Scanner** | On expeditions a scanner panel appears (bottom-right). **SCAN (Q)** gives Weak/Moderate/Strong/Pinpoint, a direction arrow (kit 2+), depth (kit 3+), material (kit 4 or Echo-Sounder in the jungle). Readings can be false: mineral deposits and empty pockets exist. **DIG HERE** appears when pinpointed. Hidden caches have **no marker** — look for odd soil, shards, stone rings, broken statues, glinting rocks. |
| **Excavation** | Choose **Brush / Trowel / Pick**, then hit the gold zone on the timing meter (button, Space or gamepad A). Misses and harsh tools on fragile finds lower the **condition**: Perfect ×1.25, Clean ×1, Damaged ×0.6 value & income. Very fragile ordinary finds can break into fragments (you're warned first). Walking away keeps the find buried for you — no re-rolls. |
| **Puzzles** | Ruins: read the Watchers, step SUN → MOON → STAR. Jungle: read the 4 steles (path, behind the waterfall, ruined statue, Root Chamber) and turn each Guardian to its beast. Root Chamber: scan the cracked wall near the collapsed ruins, then break it with a pick. Sanctum: the Root Chamber plaque says which floor stone holds the Sun Disk (Mythic); wrong stones are decoys and lock the sanctum for you for 10 min. |
| **Journal** | New tabs: **Clues** (every inscription you read, secrets solved, excavations per zone) and **Feats** (14 one-time achievements with cash rewards). |
| **Security** (🛡️) | Buy Door Locks, Cameras, Pressure Alarms, Reinforced Glass. They appear in your museum (real camera models, glass tint, pressure pads, lock plaque) and are exactly what thieves must beat. Incident log included. |
| **Heists** (🕵️, Level 2) | Pick an online target, choose up to 3 gadgets (Tools → Heist Gear), confirm the risks. Pick the front-door lock, stay out of camera view (Sneak / Jam cameras), steal one exhibit (cut glass or lift it off the pressure pad), run to the **GETAWAY** cart. Suspicion 100 = alarm → 60 s until police. The owner can press **Apprehend** near the thief. Caught = exhibit returned, 45 s jail, small fine paid to the owner. Escaped = the item really changes owner; victims with the Security System get 20% insurance. Protection: new players (Level < 2 or < 30 min play), 20 min after being robbed, 2 attempts per target per hour, cooldowns. Leaving/resetting mid-heist never keeps loot. |
| **Collectors' Market** (🏪) | Browse (search, type, rarity, price range, sort, pages), Sell (limits and the 5% fee shown first), My listings (cancel) and history. Works across servers in a published game. Inventory has a **Market** button. |
| **Trading** | Players (👥) → **Trade**. Both add items/cash, both **Lock**, both **Confirm** — any change unlocks both. |

### Studio setup for Update 2
Nothing new to create by hand. Remotes, terrain, zones and collision groups are made by the server at start-up.
- **Saving, ledger & market across servers** need *Game Settings → Security → Enable Studio Access to API Services* (and a published place). Without it everything still works **inside one test session** (local mode) and nothing is saved.
- Max Players stays **8**.

### Testing Update 2
1. **Solo:** Play → Travel → Forgotten Ruins → walk near the glinting rocks south-west of the arrival (decoy) and the dark soil patch west of the buried arch → SCAN until Pinpoint → DIG HERE → pick a tool → time the strokes. You should get a discovery card showing the condition.
2. **Puzzle:** press E on each Watcher statue's stele (Journal → Clues fills up), then step SUN, MOON, STAR on the temple plates → the door opens.
3. **Jungle:** to test quickly, give yourself money: in the Studio **Command Bar** during Play (server), run
   `local p=game.Players:GetPlayers()[1] require(game.ServerScriptService.Server.Services.EconomyService).Add(p, 50000, "test")`,
   build to Level 3, then travel to the Jungle Temple.
4. **Heist / trade / market (2 players):** Test → Clients and Servers → **2 players** → Start. Give both players cash (command above with index 1 and 2), build both to Level 2, display items, buy Lockpicks in Tools → Heist Gear. The protection rule needs 30 min of play time — to test right away, temporarily set `HeistConfig.TargetMinPlaySeconds = 0` in `src/shared/HeistConfig.luau`.
5. **Unit tests** (no Studio needed): install the Luau CLI, then run `luau tests/run_tests.luau` — 19 tests cover ledger transfers, market sales/races/crash recovery and minigame timing.

## Part 6 — Troubleshooting

| Problem | Fix |
|---|---|
| Rojo "Connect" fails | Make sure the Rojo server is running in VS Code (Rojo menu shows the project as serving). Plugin and server versions should match — reinstall the plugin from the Rojo menu. |
| Explorer doesn't show `Shared`/`Server`/`Client` | You connected before starting the server, or opened the wrong folder. Open the folder containing `default.project.json`. |
| `Infinite yield possible on ReplicatedStorage:WaitForChild("Shared")` | Rojo isn't connected (the scripts aren't in the place). Connect Rojo, then Play. |
| Red banner "Progress is NOT being saved" | Publish the place and enable **Studio Access to API Services** (Part 3.1). |
| Kicked: "We couldn't load your museum right now" | Roblox DataStores were down or blocked — this protects your data. Rejoin. |
| Kicked: "This server has no free museum plots" | More than 8 players. Set Max Players to 8. |
| Nothing happens on a green pad | Only the plot owner can buy. Check you have enough cash (a red toast tells you). |
| "You need the Security System upgrade…" | Legendary/Mythic items need the Security System; Mythic needs the Treasure Vault. |
| Emoji icons on the menu show as boxes | Replace the `Icon = "🎒"` strings in `src/client/Main.client.luau` with short words. |
| Any red error in Output | Copy the full red text + the line it points to and send it to me. |
